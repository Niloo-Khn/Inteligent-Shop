# Inteligent Shop

Seller dashboard for the generic multi-shop commerce platform. It connects to `Inteligent-Shop-backend` on port 4100 and runs locally on port 4180.

```bash
npm install --cache .npm-cache
npm run build
npm run serve
```

Current UI includes seller authentication, shop creation/switching, overview metrics, product publishing/editing, order history, and buyer accounts. Promotion and recommendation API contracts are available in the backend and will receive richer editors next.
